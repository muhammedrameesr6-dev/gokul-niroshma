## 🚀 How to Run Locally

You can simply open `index.html` in any browser:

```bash
open index.html
```

Or run a local development server using Node.js:

```bash
npx serve .
```

---

## 🌐 Deploy to Vercel in 1 Click

To publish this website live on Vercel:

1. Install the Vercel CLI (if not already installed) and log in:
   ```bash
   npx vercel login
   ```
2. Deploy the project:
   ```bash
   npx vercel --prod
   ```
   Follow the brief terminal prompts (select current directory, accept defaults). Vercel will give you a live production URL (e.g. `https://gokul-nirooshma-wedding.vercel.app`).
